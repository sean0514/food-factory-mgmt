# 食品工廠管理系統

小型食品工廠的內部管理系統。技術架構沿用「境外實習生管理系統」的做法：
**Google Apps Script（後端）+ 單一 HTML 檔（前端 SPA）+ Google 試算表（資料庫）**，
免架站、免資料庫維運，適合小型工廠（使用者 < 20 人）規模。

## 模組

1. 原料與庫存（原料主檔、供應商、進貨單、庫存異動）
2. 生產管理（生產批次、用料明細、生產費用）
3. 成品與出貨（成品主檔、成品庫存、客戶主檔、出貨單）
4. 客戶請款明細（依客戶＋期間彙總出貨紀錄開請款單，追蹤應收帳款狀態）
5. 品質/食安（可自訂檢驗範本與項目、檢驗紀錄）
6. 成本分析（生產批次成本試算、月度成本報表、原料成本波動）
7. 零用金對帳（流水帳＋餘額，食材類支出可自動連動原料進貨/庫存）
8. 損益表（逐月，科目可自動彙總其他模組數字或手動輸入，合夥分潤追蹤）
9. 使用人員與角色權限（動態權限矩陣，系統管理員永遠全模組 edit）

## 部署方式

1. 打開一個 Google 試算表 → 擴充功能 → Apps Script
2. 把 `apps-script/Code.gs`、`apps-script/Index.html`、`apps-script/appsscript.json`
   的內容分別建立/覆蓋貼上
3. 部署 → 網頁應用程式，執行身份選「以我的身份執行」
4. 第一次登入用預設帳號 `admin` / `admin123`（見 `Code.gs` 的 `ensureSeedAdmin_`），
   請登入後立即到「使用人員」改密碼或新增其他系統管理員帳號

詳細架構、資料表設計、待辦事項見 `apps-script/HANDOFF.md`。
